# Mario - 2D game engine in JAVA 🍄

A 2D game engine built from scratch in Java, using LWJGL, GLFW, OpenGL, and Gradle.

This project is currently under active development. The goal is to build a modular and extensible game engine while learning the fundamentals of game-engine architecture, rendering, input handling, scenes, cameras, textures, shaders, and game objects. 

> Status: 🚧 In Development
### Tech Stack 
| Technology | Purpose                           |
| ---------- | --------------------------------- |
| **Java**   | Core programming language         |
| **LWJGL**  | Java bindings for OpenGL and GLFW |
| **GLFW**   | Window & input management         |
| **OpenGL** | Rendering                         |
| **GLSL**   | Shader programming                |
| **Gradle** | Build & dependency management     |
| **Git**    | Version control                   |

### Repository Structure
```text
Mario/
├── assets/          # Game assets
│   ├── images/
│   └── shaders/
├── src/main/java/
│   ├── components/  # Game components
│   ├── jade/        # Core engine systems
│   ├── renderer/    # Rendering & textures
│   ├── util/        # Utility classes
│   └── Main.java    # Entry point
├── build.gradle     # Gradle configuration
└── settings.gradle  # Project settings
```
